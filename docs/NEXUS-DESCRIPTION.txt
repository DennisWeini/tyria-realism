Nexus has hidden the mod for manual moderation review. Do not treat the Nexus file as available or attempt to bypass that review. This repository provides the requested source code, build steps and checksums for inspection.

[b]VARIANTS[/b]
Universal Lite is the low-cost visual profile for AMD, NVIDIA and Intel candidates. Balanced adds bloom; Quality adds depth-based AO. The AMD RDNA4 neural route was tested on RX9070XT. RTX50 now has a guarded DLSS5-Feeder preparation, but no NVIDIA/GW2 live test by this project. RTX20/30/40 neural rendering currently requires an external modified proprietary NVIDIA NR DLL and remains manual, unsupported research.

[b]INSTALL[/b]
Close GW2, extract the current toolkit and run Setup.cmd. On RX9070XT choose AMD RX 9000 neural. Start GW2 and use F6 for neural on/off, F5 for paired captures and Home for ReShade. If you also want a stronger visual grade, close GW2 and run Setup.cmd again to add only one of Universal Lite, Balanced or Quality. Vortex deploys the _TyriaRealism folder; runtime installation remains a separate reversible step. Existing ReShade with add-on support is required for visual and RTX50 routes.

[b]NVIDIA FILES[/b]
No NVIDIA DLL, model weights or neural consumer is hosted here. RTX50 users supply valid NVIDIA-signed nvngx_dlssnr.dll and nvngx_dlss.dll plus exactly one external consumer. The upstream Feeder directs RTX20/30/40 users to the RenoDX Discord for a modified DLL; Tyria Realism found no stable public release or redistribution grant and therefore does not mirror or auto-download it. [url=https://github.com/DennisWeini/tyria-realism/blob/main/docs/NVIDIA-VARIANTS.md]Full NVIDIA guide[/url].

[b]TEST BOUNDARY[/b]
Setup completion is not proof of neural inference. On RTX50 the dlss5-feed.log must show feature18/model creation and continuing frames. On AMD, actual inference was observed only on RX9070XT. Image gains are scene-dependent and this is not a texture replacement, native DLSS Super Resolution, FSR4 or frame generation.

[b]UNINSTALL[/b]
Close GW2 and run Uninstall.cmd before removing the toolkit/Vortex deployment. Installers use backups and receipts; changed files are retained for review.
